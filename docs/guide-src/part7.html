ACommand reference

Run ghmirror -c ghmirror.yaml <command>, or docker compose run --rm engine <command> in deploy/compose/. The config path is preset in the container.

CommandPurpose
initGuided setup: writes ghmirror.yaml, .env, identities.yaml, secrets/. Flags: --dir --owner --owner-type --github-auth app|token --github-token --new-app --webhook-url --target-names --target NAME=LINE --group --include --alert-webhook --callback-port --callback-bind --yes.
checkGitHub access, admin tokens, groups (created if missing), side channels. Exit 1 on any failure.
runThe service: webhook receiver on /webhook, /healthz, /metrics, /status, queue workers, scheduler.
sync [--repo R] [--full] [--org] [--no-git] [--no-meta]One-off sync without the queue. Exit 3 if the guard halts.
enqueue-allQueue a full pass for every selected repository (the service works through it).
verify [--repo R] [--repair] [--format json|markdown] [--output F]Parity report. Exit 1 on drift. --repair re-syncs drifted objects. --format markdown prints the readable report (chapter 14); --output also writes it to a file.
statusMode, queue, last parity report, recent alerts (JSON).
guard status|resetShow or clear the deletion-guard halt.
promote --primary NAME [--yes]Fail over to a GitLab target. Exit 1 if any step failed (listed).
demoteUndo promote exactly, from its record (drills).
redirector [--listen ADDR]Serve old GitHub URLs as redirects to the primary GitLab.
archive-migration [--no-wait]Run GitHub's migration export now and store it in the archive.
ScriptPurpose
deploy/compose/setup.shBuild, init, check, start, first copy. Extra arguments go to init.
prepare-host.shRun on a GitLab host as root: --pubkey --container --ssh-host --ssh-port --bot --token-days.
e2e/run_e2e.shThe end-to-end test (needs Docker and a GitHub token; creates and deletes its own repositories).

BConfiguration reference

ghmirror.yaml. Any value can be ${VAR} or ${VAR:-default}, taken from the environment (.env). Defaults are shown.

KeyMeaning
source.owner, owner_type (org)GitHub organization or user, and its type.
source.api_url, web_urlFor GitHub Enterprise Server (default github.com).
source.auth.app_id, app_private_key_file, app_installation_idGitHub App authentication (or app_private_key inline).
source.auth.token…or a classic PAT.
source.auth.migration_tokenOptional classic PAT (repo, admin:org) for the weekly migration archive.
source.webhook_secretHMAC secret for webhook signatures.
source.repos.include (["*"]), excludeGlob patterns on repository names.
targets[].name, url, token, groupOne entry per GitLab: name, base URL, admin bot token, top-level group.
targets[].side_channelCommand prefix that runs a program on the GitLab host (ssh … sudo, or docker exec -i NAME). Omit to disable.
targets[].visibility_cap (private)Most open visibility a mirrored project may get.
targets[].mirror_url, git_urlHow the other GitLab reaches this one (push mirrors after promote); a git URL override.
targets[].ci_config_pathOptional external CI configuration path set on each project, for example pipelines/{repo}.gitlab-ci.yml@{group}/ci-config.
state.databasepostgresql://… (compose) or sqlite:///….
state.mirrors_dir, archive_dirL1 bare mirrors and L2 archive.
identity.email_domainDomain for placeholder emails of people missing from the map.
identity.email_map_file, email_mapGitHub login → company email (file next to the config, or inline).
identity.import_keys, import_avatars (true)Copy SSH/GPG keys and avatars to mirror accounts.
sync.mirror_attachments (true)Copy files pasted into issues and comments.
guard.max_disappear_ratio (0.02), max_disappear_count (1)Halt when more than this share and count vanish in one pass.
schedule.repos/meta/git/org/full/verify/migrationSeconds: 3600 / 3600 / 21600 / 21600 / 86400 / 86400 / 604800.
alerts.webhook_urlSlack-compatible incoming webhook.
server.listen (0.0.0.0:8080), workersService address and worker threads.
redirect.target, base_urlRedirector destination target and public base URL.
promote.broadcast_messageBanner text shown after promote.
