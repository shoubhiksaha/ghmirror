Every screenshot in this section is from the end-to-end test. A private GitHub repository with pull requests, reviews, issues, labels, milestones, releases, bots and a deleted repository was mirrored into two GitLab CE 19.5 instances. Unless a caption says otherwise, they show the cloud GitLab as an administrator sees it. The offline GitLab is identical (§6.8).
