1Executive summary

ghmirror keeps a complete, continuously updated copy of a GitHub organization in two self-managed GitLab instances: one in the cloud and one on-premises. It copies code and also the collaboration history around it: issues, pull requests, reviews, comments, releases, people and teams.

If GitHub becomes unavailable, for example because the account is suspended, the organization is deleted or a region has an outage, one command (ghmirror promote) turns a GitLab copy into the team's primary code host. People keep their usernames, their history and their SSH keys. The only real change for a developer is the remote URL. The other GitLab then follows the new primary automatically.

Key properties

PropertyHow it is achieved
FaithfulEvery issue, PR, comment and review keeps its number, original author and original timestamps. Merged PRs show the exact diff that was reviewed. Line comments sit on the same lines.
AutomaticGitHub webhooks trigger a sync within seconds. Scheduled passes catch anything a webhook missed. A nightly parity check compares both sides and repairs differences.
Private-repo safeUses a GitHub App or token with read access to private repositories. All copies stay private on GitLab (visibility_cap).
Never destructiveNothing that disappears from GitHub is deleted from GitLab. A deleted repo is archived, and a deleted issue is closed and labelled. A sudden mass disappearance halts all writes.
Reversible failoverpromote records each change as it makes it, and demote undoes it exactly. That lets the team run monthly failover drills safely.
Quick to set upOne command on the engine host (./setup.sh) asks a few questions, creates the GitHub App, checks every connection and starts mirroring. Each GitLab host is prepared by one line that setup prints. No manual GitLab or GitHub configuration (section 5).
Independent of GitHubBesides the two GitLab copies, the engine keeps bare git mirrors and a raw JSON archive of all metadata on its own disk. A lost GitLab is rebuilt from the other one, and the code alone can be pushed back from the bare mirrors (section 7.5).
StatusThe engine is built and tested end to end against a real GitHub account and two GitLab CE 19.5.3 instances. The final run passed every check, including a full failover drill (section 8). Organization teams, GitHub App authentication, wikis and LFS are implemented but were not exercised end to end, because the test account is a personal account (section 9). The one-command setup was tested from scratch over real SSH (section 8.3).
